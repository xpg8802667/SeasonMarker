# Season Marker

Emby 的 STRM 片头标记插件，用来补上 Emby 不主动分析 STRM 片头的问题。

当前版本：`1.2.7.0`

## 功能

- 分析 STRM 剧集片头
- 按媒体库、电视剧、季、集浏览
- 修改单集片头结束和片尾开始时间
- 重新分析本季或单集
- 新增剧集后自动增量分析
- 支持 Emby 计划任务
- 分析并发可设置为 `1–8`

自动分析只处理片头，片尾需要手动设置。

## 安装

1. 下载仓库中的 `SeasonMarker.dll`。
2. 复制到 Emby 配置目录：

   ```text
   /config/plugins/SeasonMarker.dll
   ```

3. 重启 Emby。
4. 在“控制台 → 插件”中打开 `Season Marker`。

升级时直接替换 DLL，然后重启 Emby。

## 使用

### 手动修改

进入“媒体浏览”，依次选择媒体库、电视剧、季和剧集。点击单集后可以修改：

- 片头结束时间
- 片尾开始时间

片头开始固定为 `00:00:00`。单集手动保存后，不会被普通自动分析覆盖。

### 分析片头

- 季度页面可以重新分析整季。
- 单集编辑页面可以重新分析当前集。
- “自动分析”页面可以开启新增剧集增量分析。
- “控制台 → 计划任务”中可以手动运行或设置定时任务。

## 注意

- 支持 Emby `4.9.5.x`。
- 需要在电视剧媒体库中启用片头标记。
- Emby 原生片头功能需要 Premiere。
- 分析时会读取每集开头约 10 分钟的媒体数据。使用网盘 STRM 时，建议把并发保持为 `1`。
- 插件调用了 Emby 4.9.5 的内部片头分析接口，升级 Emby 后可能需要重新适配。
